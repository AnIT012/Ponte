# 仕組み — `lang/` の中

依存は Python 3.11 の標準機能だけ。約5,000行。

```
 .lang ──parser──▶ 木（見出しと節） ──checker──▶ エラー32種・警告
                        │
                        ├──examples──▶ example と never を流す → 穴さがし
                        │
                        ├──fill──▶ AIに action の中身を書かせる ⇄ 確かめて問題を返す
                        │
                        └──runtime──▶ 実行エンジン ──server + page.html──▶ ブラウザの画面
```

## ファイル

| ファイル | すること |
|---|---|
| `parser.py` | 行の字下げで木にする。行頭が見出し（thing / rule …）、字下げが節。`#` はコメント、`##` は止めるコメント（`#4F46E5` のような色は値）。`use` で別ファイル・`use std/…` で標準ライブラリを読む |
| `checker.py` | エラーを探す。1つの決まり＝1つの関数（`ALL_CHECKS`）。E32 の型は rule ごとに this が何の thing かを推論して確かめる |
| `forms.py` | rule の when・do・値の書き方の一覧。**チェッカーも説明もここから作る** |
| `body.py` | action の中身（do と shape）を動かす。`TOOLS` が道具の一覧（**説明・エラーの一言・仕様書の表もここから**） |
| `examples.py` | example を実行エンジンで流す。`holes()` が穴さがし |
| `runtime.py` | 実行エンジン。箱（データ1件）ごとに鍵1つ、箱をまたぐと並列。flow・who・relate・通知・取り消し。保存は JSONL の追記（読み直して同じ中身に戻る） |
| `server.py` | 標準の http.server。画面の組み立て（scene → 部品の JSON）、入力の検査、リアルタイム（SSE） |
| `page.html` | 画面そのもの（素の HTML / CSS / JavaScript。ライブラリ無し）。ダークモード・スマホ・英語 |
| `fill.py` | AIに中身を書かせる。urllib で API を呼ぶ（SDK 無し）。書いた中身は example と never で確かめ、ダメなら問題を返して書き直させる |
| `guide.py` | AIへの書き方の説明を、`TOOLS`・`forms.py`・std から作る（`lang guide`） |
| `fmt.py` | 整形。見た目の幅でそろえる。意味が変わるなら書かない |
| `build.py` | 1つの .pyz にまとめる（std も入る） |
| `values.py` | 日時・期間の読み書き |
| `icons.py` | 画面のアイコン |
| `cli.py` | コマンド |
| `std/` | 標準ライブラリ。中身もこの言語で、example 付き |

## 大事な決まり（実装の側）

- **一覧は1か所だけ。** 道具（`body.TOOLS`）、rule の書き方（`forms.py`）、機械で確かめる never（`fill.MACHINE_NEVERS`）。説明・エラー・仕様書の表はそこから作り、ずれたらテストが落ちる（`tests/test_guide.py`）。
- **年は推測しない。** 年の無い日付は年の無いまま持つ。「今より前」の締切は画面で聞き返す。
- **書いてないことは誰もできない。** who に無い操作は、画面のボタンも出さないか押せなくする。
- **例が通っても、確かめていない所は言う。** `lang test` の穴さがし。
