# 入門 — やることアプリを作る

やることアプリを、エラーを見ながら1歩ずつ作ります。できあがりは [spec/todo.ponte](../spec/todo.ponte) です。
ここに出てくるエラーは、実際に `python -m ponte check` / `test` を流したときの出力そのままです。

用意するものは Python 3.11 だけです。入れる前に試したいときは、ホームページの「試す」でブラウザの中で書いて確かめられます。

---

## 1. データの形を書く

```
thing Task
  title   text
  due     monthday
  owner   User  gone[remove too]
  status  [todo | done]

thing User
  name text

flow Task.status
  todo -> done -> todo
```

- `thing` はデータの形です。`status [todo | done]` は「この2つのどれか」という状態です。
- `owner User` は別の thing（User）を指す項目です。`gone[remove too]` は「User が消えたら、この Task も消す」という意味です。
- `flow` は状態の流れです。矢印のとおりにしか動きません。

チェックしてみます。

```
$ python -m ponte check todo.ponte
渡せません（2件）
  todo.ponte:1  E19  thing Task: 誰が何をできるか（who）が1行もありません。書いてないことは誰もできません
  todo.ponte:7  E19  thing User: 誰が何をできるか（who）が1行もありません。書いてないことは誰もできません
  （直し方: ponte explain E19）
```

**書いていないことは、誰にもできません。** なので「誰が何をできるか」を決めないと先へ進めません。

## 2. 誰が何をできるか

```
who
  user  can see     Task where owner is me
  user  can change  Task where owner is me
  user  can see     User where it is me
```

自分のやることだけが見えて、自分のものだけを変えられます（消せるようにするなら `user can remove Task where owner is me` も足します）。

## 3. ボタンを押したら終わりにする

```
rule Finish
  when  user taps done-button on Task
  do    move this to finished
```

```
$ python -m ponte check todo.ponte
渡せません（1件）
  todo.ponte:20  E32  rule Finish: Task に「finished」という状態はありません（todo / done）
  （直し方: ponte explain E32）
```

打ち間違いは、動かす前に止まります。`done` に直すと通ります。エラーの意味が分からないときは `python -m ponte explain E32` で、なぜ止めたのかと直し方が出ます。

```
$ python -m ponte check todo.ponte
決めてないことなし。AIに渡せます
```

## 4. 確かめる（example）

check が通っても、**本当にそう動くか**はまだ確かめていません。test を流すと、確かめていないところ（穴）が出ます。

```
$ python -m ponte test todo.ponte
example 0件中 0件通過
穴（example で確かめていない所 3件）
  todo.ponte:18  rule Finish: when があるのに example がありません
  todo.ponte:10  flow Task.status: todo -> done をどの example も通っていません
  todo.ponte:10  flow Task.status: done -> todo をどの example も通っていません
```

example を書きます。「前の状態 → 出来事 → こうなるはず」の順です。

```
rule Finish
  why   終わったら消えてほしい
  when  user taps done-button on Task
  where status is todo
  do    move this to done
  example
    given Task
      title  "牛乳を買う"
      status todo
    taps done-button on Task
      title "牛乳を買う"
    expect Task is done
      title "牛乳を買う"
```

`where status is todo` は「まだのときだけ」という意味です。合わないとき、この rule は静かに起きません（ボタンも押せなくなります）。

`done -> todo` の穴は、「戻す」ボタンの rule（Reopen）と、その example で埋まります。できあがりのファイルで確かめてみてください。

## 5. きっかけは出来事だけ

「期限が明日なら知らせる」をこう書くと、止まります。

```
rule Remind
  when  due within 1 days
  do    notify owner "{title} の期限です"
```

```
$ python -m ponte check todo.ponte
渡せません（1件）
  todo.ponte:23  E07  rule Remind: when は出来事だけです。「due within 1 days」は状態なので where に書いてください
  （直し方: ponte explain E07）
```

「期限が近い」は**状態**なので、いつ起きるかが決まっていません。きっかけ（出来事）は「毎朝8時」にして、状態は一覧（list）で絞ります。

```
list Soon
  of     Task
  where  status is todo
  where  due within 1 days

rule Remind
  why   明日までのものを忘れない
  when  every day at 8:00
  do    notify owner each of Soon
```

`notify owner each of Soon` は「Soon のそれぞれを、その Task の owner に知らせる」という意味です。

## 6. 画面

```
scene Home
  tab[todo | done] = todo
  top     Header
  top     tabs tab
  main    stats Todo, Done
  main    match tab
    todo -> Todo as list
    done -> Done as list
  bottom  button add named add-task icon plus

input AddTask
  title  required
  due    from now

look Todo as list
  title   title
  sub     due
  button  done-button  named finish  icon check  tone good
  empty   todo-empty
```

- `scene` は画面、`look` は一覧の見せ方、`input` は入力です。
- 画面に出る文字は `words ja` / `words en` に書きます（書き忘れもエラーになります）。日本語だけのアプリなら words は書かずに、`named "終わった"` のように直接書いてもかまいません。

動かしてみます。

```
$ python -m ponte run todo.ponte
動いています: http://127.0.0.1:8000/
```

## 7. 人に使ってもらう

公開する前に、3つ確かめます。

```
$ python -m ponte check todo.ponte --publish    # 公開する時の検査（読み上げ対応も）
$ python -m ponte test todo.ponte --strict      # 穴が1つでもあれば失敗
$ python -m ponte build todo.ponte              # 1つのファイルに → python todo.pyz
```

決めたことを、コードを読まない人に見てもらうこともできます。データ・流れ・誰が何をできるか・きまりとその理由・残っていることを、1枚のページにまとめます。

```
$ python -m ponte doc todo.ponte                # → todo.html
```

ほかの人にも使ってもらうときは、ログインを付けて動かします。`--login` を付けないまま外に開こうとすると、Ponte が止めます。

```
$ python -m ponte user add todo.ponte taro      # 合言葉を聞かれます
$ python -m ponte run todo.ponte --login --host 0.0.0.0
```
