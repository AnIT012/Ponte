# 文章の書き方

Ponte のドキュメント（README・入門・仕様書・しくみ・ホームページ・エラーの説明）を書くときの決まりです。
日本語の技術文書で広く使われている「JTF日本語標準スタイルガイド」と、textlint の `preset-ja-technical-writing` を土台にしています。
Python や Rust の日本語ドキュメントのような、落ち着いた読みやすい文章を目指します。

## 1. 文体

- 本文は「です・ます」で書きます。仕様書も同じです。
- 表のセルと、名詞だけの短い箇条書き（「文字」「数」など）は、体言止めでかまいません。1つの表・1つの箇条書きの中ではどちらかにそろえます。
- 1文は 80 字くらいまでにします。長くなったら2つに分けます。
- 読点（、）は1文に3つまでにします。
- 「〜かもしれません」「〜と思います」のような弱い言い方は使いません。決まっていることは言い切ります。

## 2. 表記

ひらがなで書くもの（形式名詞・補助動詞・副詞・接続詞など）:

| 書かない | 書く |
|---|---|
| 時（「〜する時」） | とき |
| 事・所・物（形式名詞） | こと・ところ・もの |
| 無い・無し | ない・なし |
| 出来る | できる |
| 全て・全部 | すべて（「全部」は話し言葉なので避ける） |
| 要る | 必要です |
| 〜して下さい | 〜してください |
| 又は・及び | または・および |
| 様に | ように |
| 等 | など |
| 既に・更に・殆ど | すでに・さらに・ほとんど |

- 「時刻」「時間」のように、時そのものを指すときは漢字のままです。
- 半角の英単語・コードと日本語の間には、半角スペースを1つ入れます（`thing には`）。数字と単位・助数詞の間は空けません（5MB、3件）。
- かっこは全角の（）を使います。コードや英語だけを囲むときも同じです。
- 句読点は「、」「。」です。
- 文の終わりには「。」を付けます。箇条書きの項目が文なら「。」を付け、名詞だけなら付けません。

## 3. 用語

同じものは、いつも同じ言葉で呼びます。

| 言葉 | 意味 | 使わない言い方 |
|---|---|---|
| 仕様 | `.ponte` ファイルに書いた内容全体 | 決めごと・要件 |
| ルール | `rule` で書いたもの | 決まり・きまり |
| 項目 | thing の中の1つ1つ（`title` など） | フィールド |
| 状態 | `[todo \| done]` のどれか | ステート |
| レコード | thing の1件分のデータ | 箱 |
| 例 | `example` | テストケース |
| AI の担当部分 | action の中身 | 穴（「まだ例で確かめていない部分」を指す「穴」は、`ponte test` の用語なので使ってかまいません） |

- 「書き方の決まり」のように、一般的な意味で「決まり」を使うのはかまいません。
- 造語は増やしません。新しい言葉が必要なら、この表に足してから使います。

## 4. AI っぽさを出さないために

機械が書いたように見える文章には、決まった癖があります。次のことを避けます。

- 太字を多用しない。1つの節に1か所までにします。段落の頭を毎回太字で始めることもしません。
- ダッシュ（—）を使わない。見出しの「thing — データの形」のような区切りも、「thing（データの形）」か、見出しと本文に分けて書きます。
- ★などの記号で飾らない。
- 中黒（・）でことばを並べ続けない。3つ以上並ぶときは、文にするか箇条書きにします。
- 対句や決めぜりふを繰り返さない。「人は決めて、AIが書いて、言語が守る。」はキャッチコピーとして、トップページと README の冒頭に1回ずつだけ使います。
- 体言止めを続けない。「〜だけ。」「〜ならエラー。」のような切れた文を並べず、「〜です」「〜になります」と文にします。
- 「そのまま」「ちゃんと」「なので」を多用しない。「なので」は書き言葉では「そのため」「このため」にします。
- ものを人のように書かない。「Ponte が教えてくれます」ではなく「Ponte がエラーとして示します」と書きます。
- かっこ書きの補足を重ねない。1文にかっこ書きは1つまでにします。補足が長いなら、次の文に書きます。
- 聞かれてもいない比喩を入れない。「アセンブリのように下に隠れる」のような比喩は、なくても伝わるなら消します。

## 5. 確かめ方

`tests/test_japanese.py` が、2章の表記と4章の記号（ダッシュと★）を機械で確かめます。
もっと細かく見たいときは textlint を使います（Node.js が必要です。任意）。

```
$ npx textlint --preset ja-technical-writing docs/*.md
```
