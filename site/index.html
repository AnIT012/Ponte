Ponte は、アプリの決まりを書いて、そのまま動かすためのプログラミング言語です。決まっていないことがあれば、動かす前に教えてくれます。 詳しく › ブラウザで試す ›

# データの形：やることと、その持ち主
thing Task
  title  text
  due    monthday
  owner  User  gone[remove too]
  status[todo | done]

thing User
  name  text

データの形を書く

thing には、アプリが持つデータの形を書きます。項目の名前と型を並べておけば、保存や読み書きは Ponte が引き受けます。状態は [todo | done] のように、取りうる値を全部書いておきます。

# 状態の流れと、誰が何をできるか
flow Task.status
  todo -> done -> todo

who
  user  can see     Task  where owner is me
  user  can change  Task  where owner is me
  user  can see     User  where it is me

流れと、誰が何をできるか

flow には状態がどう移れるかを、who には誰が何をしてよいかを書きます。who に書いていない操作は誰にもできないので、権限の書き忘れはエラーとして見つかります。

# 毎朝8時に、明日までのやることを知らせる
list Soon
  of     Task
  where  status is todo
  where  due within 1 days

rule Remind
  why   明日までのものを忘れない
  when  every day at 8:00
  do    notify owner each of Soon

きっかけと、やること

rule には、きっかけとやることを一組で書きます。when に書けるのは時刻やボタンのような出来事だけで、「明日まで」のような条件は list の where で絞ります。

# ボタンを押したら終わりにする。例を書くとテストになる
rule Finish
  when   user taps done-button on Task
  where  status is todo
  do     move this to done
  example
    given   Task
      title   "牛乳を買う"
      status  todo
    taps    done-button on Task
      title   "牛乳を買う"
    expect  Task is done
      title   "牛乳を買う"

例がそのままテストになる

rule の下に example を書くと、それがテストになります。ponte test は例が通るかを確かめるだけでなく、まだ例で確かめていないルールや状態の変化も教えてくれます。

# AIに任せる処理には、例と禁止事項を先に書く
action FindDeadline
  in       mail text
  out      found monthday | missing
  example  "10/15まで"     -> found 10/15
  example  "来週中に提出"  -> missing
  never    guess the year
  never    fail
  else     ask user
  by       ai

AIに任せる部分には約束を

処理の中身をAIに書いてもらうときは、action に入力と答えの例、してはいけないことを先に書きます。AIが書いた中身はこの約束に照らして機械で確かめられ、守れていなければ書き直しになります。

# まだ決めていないことは tbd に書く。残っているうちは動かない
tbd
  締切を過ぎたやることは、一覧に残すか消すか

決めていないことは tbd に

まだ決めていないことは tbd に書いておけます。tbd が残っているあいだは ponte check が通らないので、決め忘れたまま動き出すことはありません。
