Ponte

アプリの決まりを書いて、そのまま動かす言語です

Ponte では、どんなデータを持つのか、状態がどう変わるのか、誰が何をしてよいのかといったアプリの決まりを書きます。書いた内容はそのまま動くアプリになり、決まっていないところがあれば、動かす前に教えてくれます。

GitHub で見る 試してみる

特徴

Ponte でできること

決まりをそのまま書けます

データの形、状態の流れ、誰が何をしてよいか、画面の見せ方までを、同じ書き方で書けます。プログラムの細かい手順は書かなくてよいので、読み返したときに「このアプリは何をするのか」がすぐに分かります。

thing Task
  title   text
  status[todo | done]

flow Task.status
  todo -> done -> todo

who
  user  can change  Task where owner is me

決まっていないと動きません

存在しない状態を書いたり、誰が操作できるかを書き忘れたりすると、動かす前にエラーになります。まだ決めていないことは tbd と書いておけば、決めるまで先に進まないようになっています。

$ ponte check todo.ponte
渡せません（1件）
  todo.ponte:42  E32  rule Finish:
  Task に「finished」という状態は
  ありません（todo / done）

確かめていないところを教えてくれます

ルールごとに「この状態でこうしたら、こうなる」という例を書いておくと、それをテストとして実行します。例が一つもないルールや、どの例でも通っていない状態の変化があれば、それも一覧にして教えてくれます。

$ ponte test todo.ponte
穴（example で確かめていない所 1件）
  flow Task.status: done -> todo を
  どの example も通っていません

AIに任せる部分には約束を付けます

メールから締切を取り出すような処理は、AIに中身を書いてもらうこともできます。その場合も、入力と答えの例や「年を推測しない」といった禁止事項を先に書いておくので、AIが書いたものはその約束を守っているかどうかを機械で確かめてから使われます。

Python だけで動きます

裏では Python が Ponte を読んで動かしていますが、ふだん Python を書く必要はありません。追加で入れるライブラリもないので、Python があればすぐに試せます。1つのファイルにまとめて持ち運ぶこともできます。

画面も一緒についてきます

一覧、ボード、カレンダー、入力フォームなどの画面を、見せ方を書くだけで用意できます。スマホの幅やダークモード、日本語と英語の切り替えにも対応しています。

しくみ

人とAIと Ponte の分担

人 ＋ AI

どんなアプリにしたいか、何をしてはいけないか、まだ決めていないことは何かを考えます。AIと相談しながら書いても構いません。

.ponte

決めたことを書いておくファイルです。書いた内容はそのまま動き、書いていない操作は誰にもできません。

Python（裏）

Ponte のファイルを読んで、その通りに動かします。ふだんは意識しなくて大丈夫です。

Ponte で作ったアプリ

やること

いちばん小さな見本です。入門ではこのアプリを、エラーを見ながら少しずつ作っていきます。

spec/todo.ponte

備品かしだし

チームの備品を借りたり返したりするアプリです。返却日を過ぎると知らせてくれて、管理者も決められます。

spec/lend.ponte

はじめかた

手元で動かしてみる

1
git clone https://github.com/AnIT012/nameless-lang && cd nameless-lang
2
pip install -e .
3
ponte run spec/todo.ponte

ブラウザで http://127.0.0.1:8000/ を開くと、やることアプリが表示されます。自分のアプリを作るときは ponte new myapp で、ひな形から始められます。

いまの状態

まだできないこと

ログインは仮のものです今はURLに名前を入れるだけで、誰にでもなれてしまいます。人に使ってもらう前に、きちんとしたログインを用意する予定です。
計算の道具はまだ少なめです曜日の判定や日付の足し算などはまだありません。使おうとした場合は、エラーで教えてくれます。
向いていないアプリもありますゲームや見た目に凝ったサイトには向いていません。貸し借りや申請、記録、管理のように、決まりの多いアプリが得意です。

Ponte（ポンテ）はイタリア語で「橋」という意味です。人とAIのあいだにかける橋になればと思って名前をつけました。
