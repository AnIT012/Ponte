Ponte

AIに、勝手に決めさせない。

アプリの「決まり」を書くと、そのまま動く言語。
決めてないことがあると、動く前に「ここ決まってないよ」って止まる。

GitHub で見る 3行で試す

ほんとにあった話

「3日以内」って頼んだら、
AIは5回とも「72時間」で数えた。

わたし締切が3日以内の応募があったら、夜9時に知らせて。
たとえば 9/21 の夜なら、9/24 締切のはお知らせしてね。
AIできました！
実際は9/21 21:00 から 9/24 23:59 まで、およそ75時間。AIは「3日＝72時間」で数えたから、このお知らせは来なかった。5回頼んで、5回とも。

AIが悪いわけじゃない。「3日」って、日付で数えるのか時間で数えるのか、誰も決めてなかった。決めてないことを、AIは黙って決める。しかも、それっぽく動く。だから気づけない。

Ponte だと

決めてないなら、動かない。

Ponte では「3日以内」は最初から「日付で3日」と決まってる。言語が決めてないことを書いたら、動かす前に止まる。打ち間違いも同じ。

todo.ponte（抜粋）

thing Task
  title   text
  status[todo | done]

rule Finish
  why   終わったら消えてほしい
  when  user taps done-button on Task
  where status is todo
  do    move this to finished
  example
    given Task
      title  "牛乳を買う"
      status todo
    taps done-button on Task
      title "牛乳を買う"
    expect Task is done

ponte check 止まった

$ ponte check todo.ponte
渡せません（1件）
  todo.ponte:42  E32  rule Finish:
  Task に「finished」という状態は
  ありません（todo / done）

$ ponte test todo.ponte
穴（example で確かめていない所 1件）
  flow Task.status: done -> todo を
  どの example も通っていません

# done に直して、「戻す」rule と example を足すと
決めてないことなし。AIに渡せます
example 4件中 4件通過

しかも「ちゃんと確かめてない所」まで言ってくる。テストが通っても、安心しきれないあの感じがなくなる。

どういう分担？

あなたは決める。AIは書く。
Ponte は見張る。

あなた ＋ AI

何が欲しい？何はダメ？まだ決めてないことは？ここだけ考えればいい。AIと相談しながらでもいい。

.ponte

決めたことを書く紙。データの形、状態の流れ、誰が何をできるか、画面まで。書いたことはそのまま動く。書いてないことは、誰にもできない。

Python（裏）

Ponte を動かしてる本体。あなたは触らなくていい。インストールするものは Python だけ。ほかに何もいらない。

やること

いちばん小さいアプリ。入門で、エラーを見ながら1歩ずつ作れる。

spec/todo.ponte

備品かしだし

カメラを借りて、返す。返し忘れたら次の朝に知らせる。管理者も決められる。

spec/lend.ponte

家計メモ

「ランチ 1,200円」と書くだけで金額を拾って、合計してくれる。

spec/kakeibo.ponte

試してみる

3行で、手元で動く。

1
git clone https://github.com/AnIT012/nameless-lang && cd nameless-lang
2
pip install -e .
3
ponte run spec/todo.ponte

ブラウザで http://127.0.0.1:8000/ を開けば、やることアプリが動いてる。自分のを作るなら ponte new myapp。

まだ、ここはダメ。

ログインがまだ仮今はURLに名前を書けば誰にでもなれちゃう。人に使ってもらう前に直す。
道具が少なめ曜日とか、日付の足し算とかはまだ無い。書くとちゃんとエラーになる。
