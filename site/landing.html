Ponte

人は決めて、AIが書いて、言語が守る。

決めたことを書くと、そのまま動くアプリになる言語。決めてないことがあれば、動かす前に止まる。だからAIに渡しても、勝手に決められない。

GitHub で見る はじめる

ponte ＝ イタリア語で「橋」。人とAIの間に、決まりの橋をかける。

決めてないことは、動かない

打ち間違いも、決め忘れも、動かす前に止まる。

todo.ponte（抜粋）

thing Task
  title   text
  status[todo | done]

rule Finish
  why   終わったら消えてほしい
  when  user taps done-button on Task
  where status is todo
  do    move this to finished
  example
    given Task
      title  "牛乳を買う"
      status todo
    taps done-button on Task
      title "牛乳を買う"
    expect Task is done

ponte check 止まった

$ ponte check todo.ponte
渡せません（1件）
  todo.ponte:42  E32  rule Finish:
  Task に「finished」という状態は
  ありません（todo / done）

$ ponte test todo.ponte
穴（example で確かめていない所 1件）
  flow Task.status: done -> todo を
  どの example も通っていません

# done に直して、「戻す」rule と example を足すと
決めてないことなし。AIに渡せます
example 4件中 4件通過

.ponte

データ・状態の流れ・誰が何をできるか・ルール・画面・約束（例と禁止）。書いたことだけが動く。書いてないことは誰もできない。

Python（裏）

Ponte が読んで、その通りに動かす。写真やメールのような細かい作業も、約束の中だけで。見なくていい。依存は Python の標準機能だけ。
